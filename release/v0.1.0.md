## ✨ Features

### High-Performance Native WASAPI Engine
- **Direct Windows WASAPI shared-mode access**: Bypasses standard JavaSound's high-overhead mixer layer for direct hardware communication.
- **Ultra-Low Startup Latency**: Typical Time To First Sample (TTFS) latency reduced down to **1.2 ms - 3.5 ms** (compared to Java Sound's 45 ms - 120 ms).
- **Zero GC pressure playback loop**: Built-in state-management utilizing native memory structures, avoiding standard heap allocations.
- **Zero-Config deployment**: Pre-compiled native WASAPI DLL is bundled inside the library resources and automatically loaded at runtime.

### Technical Examples & Sub-projects
- **Standalone Demos**: Refactored in accordance with the `_BluePrint` standards, including their own clean independent POM configurations.
- **Interactive Console Demo**: Queries Windows endpoints, lists them, generates a crisp 440Hz wave beep, and shows a real-time progress bar.
- **Side-by-Side Latency Benchmark**: Side-by-side latency benchmark comparing WASAPI native against standard JavaSound, demonstrating a **~30x startup and play overhead speedup**.

## 📦 Installation

### Maven (JitPack)
Add JitPack repository and the following dependencies to your `pom.xml`:
```xml
<repositories>
    <repository>
        <id>jitpack.io</id>
        <url>https://jitpack.io</url>
    </repository>
</repositories>

<dependencies>
    <!-- 1. The FastAudioPlayer Module -->
    <dependency>
        <groupId>io.github.andrestubbe</groupId>
        <artifactId>fastaudioplayer</artifactId>
        <version>0.1.0</version>
    </dependency>
    
    <!-- 2. FastCore (Required Native JNI DLL Loader) -->
    <dependency>
        <groupId>com.github.andrestubbe</groupId>
        <artifactId>fastcore</artifactId>
        <version>v0.1.0</version>
    </dependency>
</dependencies>
```

---

## 🔧 Technical Details
- **JAR Size:** ~15 KB
- **Native Assets:** Includes `fastaudioplayer.dll` bundled directly in the JAR resources.
- **Min Platform:** Windows 10/11 (x64).

## 🎮 Running the Demos
```bash
# Clone the repository
git clone https://github.com/andrestubbe/FastAudioPlayer.git
cd FastAudioPlayer

# Run interactive console player
.\run-demo.bat

# Run side-by-side latency benchmark
.\run-benchmark.bat
```
