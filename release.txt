FastAudioPlayer v1.0.0 - Release Package
================================================================================

QUICK START (Copy & Paste)
--------------------------------------------------------------------------------

1. BUILD FAT JAR (includes native DLL):
   mvn clean package -DskipTests

2. RUN CONSOLE BENCHMARK:
   java --enable-native-access=ALL-UNNAMED -cp "target/fastaudioplayer-1.0.0.jar;examples" ConsoleBenchmark

3. RUN BASIC TEST:
   java --enable-native-access=ALL-UNNAMED -cp "target/fastaudioplayer-1.0.0.jar;." Test

4. BUILD NATIVE DLL (Windows):
   compile.bat

API EXAMPLE
--------------------------------------------------------------------------------

import fastaudio.FastAudioPlayer;

public class Demo {
    public static void main(String[] args) {
        FastAudioPlayer player = new FastAudioPlayer();
        
        // Load audio file
        player.load("music.wav");
        
        // Set volume (0.0 to 1.0)
        player.setVolume(0.8f);
        
        // Play
        player.play();
        
        // Wait for completion
        while (player.isPlaying()) {
            Thread.sleep(100);
        }
        
        player.close();
    }
}

Compile & Run:
javac -cp fastaudioplayer-1.0.0.jar Demo.java
java --enable-native-access=ALL-UNNAMED -cp "fastaudioplayer-1.0.0.jar;." Demo
